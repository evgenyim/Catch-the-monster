# Проверка версии 2.0

Проверено 27 октября 2026 года.

## Логика и сохранения

Команда: `node --test tests/*.test.mjs`. **42 теста пройдены.**

- Все 24 уровня имеют победное решение в пределах бюджета.
- Ни один уровень не выигрывается без действий игрока.
- Перебор всех более коротких комбинаций стен подтверждает минимальность заявленного решения.
- Проверены кратчайшие пути, предпочтение безопасного пути при равенстве, диагонали, недостижимые цели и циклы порталов.
- Проверены повреждённый JSON, некорректные данные, запрещённый доступ к localStorage и объединение результатов вкладок.

## Браузер

Команды: `node scripts/build.mjs`, `node scripts/serve.mjs --dist`, `node tests/ui-smoke.mjs`. Использован установленный Chrome через Playwright 1.62.1, Node.js 24.19.0. **8 групп сценариев пройдены, ошибок JavaScript и браузерной консоли нет.**

- Все 24 уровня пройдены через реальные нажатия интерфейса, собраны 72 звезды.
- Проверены старт, проигрыш, победа, повтор, отмена, очистка, блокировка поля, подсказки и улучшение результата.
- Проверены открытие карты, закрытые уровни и постепенное открытие кампании.
- Проверены настройки, восстановление черновика, перезагрузка прогресса и настоящий офлайн-reload через service worker.
- Проверены ширины 390 и 320 px, горизонтальная ориентация, сенсорное прохождение первого уровня и уровня с порталами.
- Проверены клавиатурная навигация, Escape, пауза и события нативного жизненного цикла.
- Отдельно проверен браузер с запрещённым localStorage: игра сохраняет работоспособность в памяти.

Также вручную проверены внешний вид на телефоне и широком экране и победа на первом уровне. Скриншот начального состояния: [game-preview.png](game-preview.png).

## Android

`assembleDebug`, `assembleRelease` и `lintDebug` выполнены с JDK 17, Gradle 8.11.1, AGP 8.10.1, SDK 36 и Build Tools 35.0.0. Android lint не обнаружил проблем; подпись debug APK проверена apksigner. Release APK требует пользовательской подписи для распространения.

Приложение установлено и запущено в ARM64-эмуляторе Android 16 / API 36 с отключёнными Wi-Fi и мобильными данными. Проверены загрузка локальных ресурсов, победа на первом уровне, три звезды, открытие второго уровня и сохранение. Android Back закрывает окно результата; Home и возврат приостанавливают игру и показывают «Продолжить». Горизонтального переполнения при ширине 412 px нет.

На физическом Android-устройстве и на всех поддерживаемых версиях Android тестирование не выполнялось. Android 8.0+ требует актуальный Android System WebView. Браузерные автоматические проверки проведены в Chromium, не в Safari/Firefox.

## Сохранность исходников

Все архивные файлы сверены побайтово с Git-объектами исходного master. Все четыре удалённые ветки получены и изучены; их история не переписывалась. Столкновения имён, отличающихся только регистром, устранены переименованием архивных вариантов. Исходное содержимое двух файлов рабочего каталога сохранено отдельно.
