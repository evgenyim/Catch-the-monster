# Архив прототипа

`2017/` содержит точные байты файлов из `master` (`a308ea49f4b44962102b35fe99756e1cf801f76c`), кроме корневого README, текст которого сохранён ниже. Эти исходники не участвуют в новой сборке.

Исходный Git содержит пары `Bfs.java`/`bfs.java` и `Monstrik.java`/`monstrik.java`, несовместимые с обычной регистронезависимой файловой системой macOS. Чтобы сохранить обе версии, первые переименованы в `Bfs.variant.java` и `Monstrik.variant.java`. Извлечение выполнено из Git-объектов, а не из конфликтующего checkout.

`checkout-overrides/` дополнительно сохраняет фактическое содержимое двух файлов на диске до переработки; ничего из обнаруженных локальных изменений не отброшено. Остальные исторические ветки остаются доступны в Git. Их состав описан в `docs/BRANCH_AUDIT.md`.

Исходный README:

> Наша игра о спасении персонажа от жуткого монстра. В начале игры игрок видит поле n * n, которое на самом деле является графом. На одной клетке есть персонаж, а на другой - монстр. Монстр видит персонажа и хочет его съесть. Цель состоит в том, чтобы сохранить жизнь персонажа и загнать монстра в ловушку. У игрока есть некоторые функции, такие как поставить стену или портал в одну из клеток поля. Таким образом игрок сможет обмануть монстра и тем самым завлечь его в ловушку
